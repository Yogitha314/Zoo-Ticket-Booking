# 🦁 Zoo Ticket Booking System

A simple web application that lets visitors book zoo tickets online and helps zoo staff manage ticket sales, visitor slots, and pricing.

---

## ✨ Features

### For Visitors
* **Browse Ticket Types:** View prices for adults, children, seniors, and group packages.
* **Pick a Date & Time:** Choose an available visit date and entry time slot.
* **Online Booking:** Book multiple tickets in one order and get an instant booking confirmation.
* **Digital Ticket:** Receive a booking ID or QR code to show at the zoo entrance.
* **Booking History:** View or cancel upcoming bookings.

### For Admins
* **Manage Tickets:** Add, edit, or update ticket types and prices.
* **Track Bookings:** View all customer bookings and daily visitor counts.
* **Control Capacity:** Set daily visitor limits to prevent overcrowding.
* **Verify Tickets:** Check and mark tickets as "Used" at the entry gate.
